# CyberTarot 规格与产品需求书 (Project Spec)

> **读者：** 负责实现、测试、维护或审阅 CyberTarot 的开发者与产品设计人员。  
> **定位：** 当代年轻人的“赛博防内耗指南 & 情绪投射镜”——高颜值、强交互、个性化 AI 塔罗 Web 应用。

---

## 1. 产品概述与核心价值

CyberTarot 是一款专为 00 后年轻人、打工人和学生量身定制的赛博风情境化塔罗 Web 应用。
传统塔罗应用存在三大痛点：
1. **视觉过时**：老旧西方中世纪神秘学插画，缺少现代年轻人的美学认同；
2. **术语晦涩**：因果宿命论、空洞玄学套话，脱离现代职场与生活真实困境；
3. **交互冰冷**：直接点一下弹出一堆字，缺少仪式感、沉浸感与解压触感。

CyberTarot 以 **Y2K 赛博酸性风 + 物理仪式感交互 + 4重 AI 毒舌/治愈人格 + 场景化直击痛点 + 拍立得社交裂变** 彻底重构塔罗体验。

## 2. 场景化玩法矩阵规格

### 2.1 每日日常专区 (高频留存)
1. **打工人今日班味运势 (Daily Work Vibe)**:
   - 抽牌机制：单张牌。
   - 核心输出：
     - **班味指数**：如 `82% 易被空降大饼噎住`、`35% 准点下班预备役`。
     - **今日宜 / 忌**：宜（如“假装敲键盘摸鱼”、“全冰少糖生椰拿铁”）；忌（与老板同乘电梯、主动揽非本职活）。
     - **毒舌/治愈一句话定调**：直击痛点的大白话金句。
     - **行动指南 (Action Item)**：具体的避雷或自洽方案。
2. **情绪能量签 (Mood Wallpaper)**:
   - 抽牌机制：单张大阿卡纳/小阿卡纳。
   - 核心输出：不测吉凶，测“今日宇宙背景辐射”，生成拍立得/海报级壁纸卡片。

### 2.2 职场生存专区 (打工人防内耗)
1. **老板/同事潜台词翻译器**:
   - 输入：用户输入对方的原话（如“你最近挺闲啊？”、“这个方案你再想想”）。
   - 牌阵：3 张牌。
     - Card 1: **表面态度**（字面伪装）
     - Card 2: **深层真实想法**（潜台词、利益算盘）
     - Card 3: **高情商应对/摸鱼防雷建议**（具体话术与操作）
2. **离职/跳槽二选一牌阵 (Decision Branch)**:
   - 牌阵：左右分支双向对比牌阵（各 2 张牌，共 4 张）。
     - 左侧（留在原岗位）：能量消耗预估 + 6个月精神/财务收益。
     - 右侧（跳槽/裸辞）：风险敞口 + 预期心理回血与机遇。
   - 输出：清晰的“决策天平量化对比表”。

### 2.3 情感救赎专区 (情感流量与清醒剂)
1. **Crush 意图探针**:
   - 牌阵：3 张牌。
     - Card 1: **TA 目前的真实状态**（忙碌、游移、钓鱼还是专注）
     - Card 2: **TA 对你的真实感受**（上头、权衡、朋友边界还是纯撩）
     - Card 3: **未来阻碍与走向**（破局关键点）
2. **恋爱脑清醒符 (断联/复合/海王鉴别)**:
   - 输入：当前困扰（“TA还会找我吗”、“还要继续等吗”）。
   - 牌阵：1~2 张精准牌。
   - 调性：极度清醒、拒绝无底线自我消耗，提供一针见血的劝退或断舍离指南。

### 2.4 纠结星人决策天平 (微型决策)
1. **赛博抛硬币**:
   - 针对具体冲动决策（如“要不要冲动买这件大衣”、“今晚局去不去”）。
   - 抽 1 张牌：输出 **支持率（0%~100%）**、**主要避坑点** 与 **最终决断**。

### 2.5 社交共振与裂变
1. **小红书/朋友圈风拍立得卡片生成**:
   - 3:4 / 9:16 精致比例，顶部卡牌全息镭射视觉，中间加粗梗句关键词，底部专属箴言与二维码，支持一键下载 PNG 与复制。
2. **赛博能量树洞 (Cyber Pool)**:
   - 抽牌后可匿名投掷一句情绪吐槽或祝福进入池子；
   - 支持捞取其他用户的实时匿名能量签（如“此时此刻有 2891 人和你一样抽到圣杯五”）。

## 3. AI 占卜师人格体系与 Prompt 架构

用户在洗牌前可从 4 种鲜明人格中选择一种，AI 的所有解读文风、语气和建议风格均严格遵循人格设定：

| 人格 ID | 人格名称 | 视觉徽标 | 说话风格与腔调 | 适用场景 |
|---|---|---|---|---|
| `bestie` | **毒舌嘴替闺蜜** | 💅 烈焰红唇/酸性粉 | 辛辣一针见血、专治恋爱脑、金句频出、白眼翻上天但真护短 | 测感情、防渣男、想发疯时 |
| `healer` | **温柔治愈大姐姐** | 🍵 莫兰迪绿/暖心猫 | 无条件接纳、情绪价值拉满、像冬夜热可可、充满母性与治愈包容 | 极度焦虑、受委屈、自我怀疑时 |
| `strategist` | **硬核职场军师** | ♟️ 战术蓝/冷峻灰 | 理性客观、冷酷现实主义、算计利益与风险、纯给 SOP 与 Action Items | 跳槽、跟老板对线、谈加薪时 |
| `oracle` | **神秘赛博巫师** | 🔮 全息紫/电光绿 | 荣格心理学原型、象征主义、高维宇宙俯瞰、富有哲理与意识流 | 深度探索、人生命题、迷茫期 |

### 多轮追问 (Deep Dive) 交互
解读结果呈现后，界面提供快捷追问芯片（如：“那我怎么回TA？”、“今天能准点下班吗？”、“最坏结果是什么？”）及自由输入框，支持当前牌阵上下文下的 1~3 轮即时追问。

## 4. UI/UX 规范 (基于 `ui-ux-pro-max`)

### 4.1 视觉风格：Y2K Cyber-Acid Dark
- **背景底色**：深邃纯黑与黑曜石冷夜灰（`#08090C`, `#0F1117`），点缀点状/网格 Cyber Grid 与微光发光晕。
- **酸性高饱和点缀**：
  - 酸性电光绿 (Cyber Lime): `#00FF66` / `#10E775`
  - 霓虹荧光粉 (Neon Magenta): `#FF2E93`
  - 全息电光青 (Holo Cyan): `#00F0FF`
  - 警告酸黄 (Acid Yellow): `#E2F952`
- **卡牌物理质感**：
  - 全息镭射反光涂层（根据鼠标悬浮/陀螺仪移动的高光渐变闪光效果）。
  - 双面 3D 翻转卡牌（Card Back: 赛博符文几何电路阵列；Card Front: 现代矢量极简塔罗插画 + 关键词标签）。

### 4.2 物理动效与仪式感设计
1. **洗牌动效 (Shuffling)**：卡牌在空间中呈扇形散开、对切交错回弹，伴随细腻的扑克摩擦声。
2. **切牌动效 (Cutting)**：用户点击或滑动将牌堆分成两份对调，模拟真实切牌仪式。
3. **翻牌动效 (3D Flip)**：真实的 `transform: perspective(1000px) rotateY(180deg)` 翻转，伴随清脆卡牌落桌音效。
4. **声效系统 (Web Audio API)**：内置纯合成 Web Audio 引擎，无需依赖大体积音频文件，零加载延迟生成卡牌滑动、点击与翻转特效声。
5. **震动反馈 (Haptic API)**：在移动端支持 `navigator.vibrate`，洗牌与翻牌时给予物理触感确认。

## 5. 技术架构与选型

- **框架**：Next.js / React 19 + TypeScript + Tailwind CSS (移动优先响应式设计，适配手机竖屏与桌面端)。
- **动效库**：Framer Motion + CSS 3D Transforms + Canvas。
- **图标**：Phosphor Icons (`@phosphor-icons/react`) & Lucide React（严禁使用系统原生 Emoji 作为结构性功能图标）。
- **音频系统**：轻量级 Web Audio Synthesizer（零网络依赖，实时生成物理洗牌白噪声与谐波钟声）。
- **AI 引擎**：
  - 双模驱动：
    - **内置高情商离线生成引擎**：内置精巧的 78 张牌意 + 4 大 AI 人格语料库，离线即开即用、零延迟、免去网络与 API 配置困扰。
    - **自定义大模型接入选项 (BYOK)**：设置抽屉中支持用户填入 OpenAI / DeepSeek / Gemini / 兼容服务商的 API Key 与 Base URL，实现原生流式多轮对话。
- **海报导出**：`html-to-image` / HTML5 Canvas 客户端即时渲染与高质量导出。
