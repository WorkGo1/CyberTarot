# CyberTarot 愿景地图 (Vision)

> **读者：** 想要理解「赛博防内耗塔罗指南」最终为当代年轻人和打工人创造什么体验与价值的产品与研发人员。  
> **核心定位：** 当代年轻人的**“赛博防内耗指南 & 情绪投射镜”**。

---

## 1. 产品核心与愿景本质

当代 00 后打工人与青年学生普遍处于高内耗、高不确定性、情绪压力与“想发疯又得体面”的夹缝中。传统塔罗充斥着晦涩宿命论与老派神秘学，难以贴合现代日常。
**CyberTarot** 的最小本质是：**以严肃的心理学投射机制为内核，披上趣味解构的 Y2K 赛博酸性外衣，用有仪式感的物理动效与直击灵魂的 AI 人格，提供即时情绪解压、清醒建议与社交表达**。

- **情绪价值 > 玄学预言**：不搞封建迷信与因果宿命，专注心理疏导、现实建议（Action Item）与情绪共振。
- **人话与热梗 > 晦涩术语**：把“宝剑三”、“星币骑士”翻译成“深夜emo心脏被扎成筛子”、“打工牛马稳定推进度”。
- **极度仪式感与解压感**：物理洗牌、切牌、3D 翻牌、Web Audio 触感音效与手机震动，让赛博抽牌成为下班/午休的解压仪式。


### 核心玩法场景矩阵

| 场景专区 | 玩法名称 | 牌阵与交互 | 交付结果与价值 |
|---|---|---|---|
| **每日日常** | 打工人今日班味运势 | 单张牌 (Daily Draw) | 班味指数(%)、今日宜/忌、行动指引与心理抚慰 |
| **每日日常** | 情绪能量签 | 单张牌 + 美学大图 | 不测吉凶，测能量场，生成极简治愈壁纸级美学签 |
| **职场生存** | 老板/同事潜台词翻译器 | 3张牌 (表面 / 深层潜台词 / 应对策略) | 揭秘“你再想想”、“最近挺闲啊”的真实意图，提供高情商摸鱼防雷指南 |
| **职场生存** | 离职/跳槽二选一牌阵 | 左右分支双牌阵 (各2张：能量消耗与收益) | 留原岗位 vs 跳槽裸辞，量化心理账本，治愈纠结 |
| **情感救赎** | Crush 意图探针 | 3张牌 (他当前状态 / 对你感受 / 阻碍与走向) | 暧昧期/单身专用，戳破幻想，看清真实互动动能 |
| **情感救赎** | 恋爱脑清醒符 | 单张/双张牌 | 专治断联内耗与复合执念，泼冷水或温柔劝退，阻断无底线消耗 |
| **决策天平** | 赛博抛硬币 | 单张决策牌 | 消费拦截、今晚去不去社交局，给倾向性百分比与风险防爆提示 |
| **社交共振** | 赛博能量树洞 / 能量池 | 匿名投递与打捞池 | 共享情绪共振（如“全国今天有 3420 人抽到宝剑十，你不是一个人在熬”） |
| **社交共振** | 双人合盘契合度 | 双人链接抽取比对 | 测算塑料同事羁绊度 / 灵魂合拍度，生成合体表情海报 |

## 3. 能力版图

- **卡牌与象征学引擎**：完整 78 张韦特塔罗体系，每张牌映射现代职场、恋爱、日常生活 3 套语义标签与正逆位词库。
- **物理动效与仪式感系统**：洗牌扇形铺展、切牌叠放、3D 翻转、Web Audio 空间合成声效（摩擦、撞击、鸣响）、Haptic 震动。
- **多重 AI 人格矩阵**：
  - **毒舌嘴替闺蜜**：辛辣刻薄、专治恋爱脑、金句喷射机。
  - **温柔治愈大姐姐/猫猫**：无条件拥抱、情绪价值给满、抚平焦虑。
  - **硬核职场军师**：理性客观、现实主义算盘、利益至上 Action Items。
  - **神秘赛博巫师**：仪式感、荣格心理学原型、哲学符号与高维视角。
- **社交视觉生成器**：拍立得风格、Y2K 赛博贴纸、小红书 3:4 比例卡片，带动态印章与二维码。
- **多轮 Deep Dive 引擎**：基于当前牌阵与上下文记忆，支持 1~3 轮快捷/自定义即时追问。

## 4. 探索空间与演化路线

- **Phase 1 (MVP)**：单机完全可用 Web 应用，内置完整 78 张现代塔罗数据库、全套物理动效与声效、4 大 AI 人格内置推理引擎与自定义 API Key 选项、5 大高频场景矩阵、拍立得海报生成。
- **Phase 2 (社交扩展)**：双人合盘模式、本地 IndexedDB 牌历与周报统计、赛博树洞本地/服务端共享。
- **Phase 3 (进阶体验)**：PWA 桌面/移动端一键安装，陀螺仪体感晃动洗牌。

## 5. 统一语言与阅读路径

- **班味指数**：职场内耗与疲劳程度指标（0%~100%）。
- **清醒符**：专治恋爱脑/冲动决定的心理降温机制。
- **赛博仪式感**：通过物理拟真动效与声效，降低纯文字 AI 对话的枯燥感，建立心理专注度。
